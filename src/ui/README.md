# 🧹 CleanIQ

### AI-Powered Data Cleaning & Data Quality Platform

CleanIQ is an AI-powered data cleaning platform built with **Python** and **Streamlit**. It helps users upload datasets, detect data quality issues, clean data automatically, generate AI-based insights, and export cleaned datasets in multiple formats.

---

## 🚀 Features

- 📊 Dataset Profiling
- 🧹 Smart Data Cleaning
- 🤖 AI Dataset Insights
- 🔍 Data Quality Assessment
- 🎯 ML Readiness Score
- 📈 Interactive Charts
- 📚 Data Dictionary
- 💡 AI Recommendations
- 💬 Dataset Chat Assistant
- 📜 Activity History
- 📄 PDF Report Export
- 📊 Excel Export
- 📁 CSV Export

---
